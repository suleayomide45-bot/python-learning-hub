Lesson 1: Python Basics

Python is a programming language used to build applications, automate tasks and work with data.

Here is your first Python example:

name = "Ayomide"
print("Hello", name)

This program stores a name in a variable and displays it.

Lesson 2: Conditions and Loops

Conditions allow a program to make decisions.

score = 75

if score >= 50:
    print("You passed")
else:
    print("You failed")

Loops allow us to repeat instructions.

for number in range(1, 6):
    print(number)

Lesson 3: Python Functions

Functions are reusable blocks of code.

def greet(name):
    print("Hello", name)

greet("Ayomide")

Functions help make programs organized and reusable.
